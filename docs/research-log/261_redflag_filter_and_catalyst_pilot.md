## Track 1 — the LLM red-flag filter (the doc-260 morsel, made deployable & prospective)
The one reproducible thing from doc 260 was a short-side **fader-detector** (the LLM reads financing/guidance red flags → the name fades), mechanism-consistent with doc 253 ("dilution is the distribution"). It's not a tradable long edge, but it *is* a **risk filter** with a direct live-bot application: don't buy the names the LLM flags as red. Built into `scripts/rocket_watchlist_engine_doc255.py`:
- `recent_disclosure(ticker, cik, date)` — point-in-time: SEC forms filed in the 45d before `date` + the most-recent 8-K text (no look-ahead).
- `llm_redflag(...)` — Qwen3-235B reads the 8-K + dilution filing types (S-1/S-3/424B/ATM) → `redflag` 0-1 + a ≤12-word reason; nudged up when a dilution filing is present.
- Logged per gapper (`redflag`, `redflag_reason`); `--report` adds a **high-(≥0.6)-vs-low-(<0.4) red-flag → oc_ret/rocket-rate** readout; the scheduled `MomentumX-RocketWatchlist` task now runs `--llm` so it accumulates **out-of-sample, look-ahead-immune**.
- **Verification (2026-06-03, 26 gappers, 21 scored):** the red-flag scores are sensible and mechanism-aligned, and high-flag names faded (8/9 negative on the day). *This is a one-day illustration that the wiring works — NOT validation.* The honest read comes after ~weeks of forward days (like the doc-254 insider/coiled leads).

## Track 2 — catalyst/binary-event handicapping pilot (`scripts/catalyst_handicap_pilot_doc261.py`)
The real event edge isn't predicting the binary outcome (near-random) but spotting where the **options-implied move is mispriced vs realized**. Pilot question: does the data pipeline even work for our universe? Detect biotech binary-event days (|gap|≥30%, prev≥$2, ADV≥$1M, 2024-25; 263 found) → pre-event ATM straddle implied move (Polygon historical options) vs realized.
- **Bug caught by hostility:** the first run said "0% have options" — too absolute. Polygon's contracts endpoint returns only *active* contracts unless `expired=true`; adding it flipped 0→48-50 contracts per name. (Same discipline that kills false positives, applied to a false *negative*.)
- **Real feasibility finding:** **82% of events have *listed* options, but only ~8% have a daily-traded pre-event straddle price** — the options exist but are too **illiquid** to price the implied move (trade-based aggs; historical *quotes* are a higher Polygon tier). So the implied-probability edge is measurable only on the more-liquid biotech subset (~$100M+), which is **not the micro-cap lottery universe that is our actual problem** — and there, options are untradeable, so the edge is both untestable *and* uncapturable.
- **The 3 measurable cases** (SRRK, OTLK, IOVA) show implied < realized by ~20pp — but that is a **selection artifact** of conditioning on |gap|≥30% (I picked the big movers; realized is mechanically large). Not interpretable as a premium edge.
- **Verdict:** the pipeline is proven; the universe isn't. A proper Track 2 would need a **scheduled-catalyst calendar** (PDUFA/AdCom dates known ex-ante, so no outcome selection) on the liquid subset + options **quotes** — a larger build on a narrower universe, with a prior already lowered by the correlated Stage-B failure. **Not worth building now.**
