## §3 — PRE-REGISTRATION (frozen; this section binds; committed BEFORE any panel model runs)

**Reframed question.** Cross-family LLM evaluator errors are known-correlated. The **defect-class geometry** of that correlation — against a certified potency-proven oracle, in the automated research-audit setting — is not. Practical form: **does adding a cheaper same-vendor tier (Haiku/Sonnet behind Opus) as a second checker buy independent coverage, and does the answer depend on the defect class?**

**Panel (intra-vendor, cross-capability-tier — scoped as such, never "cross-model review in general").** Opus 4.8, Sonnet 5, Haiku 4.5, plus a **same-tier lineage floor** of two independent Opus 4.8 draws; Fable 5 added if quota returns. Each model audits each item **independently**: blind (memory-free, sandboxed, no cross-talk, no ground truth), under a frozen protocol; catch∈{0,1} per (item, model, frame, replica) = did it flag the seeded defect at its site. Refusals coded as a **distinct** outcome, excluded from the catch 2×2 and reported separately (refusal-diversity axis).

**PRIMARY confirmatory estimand — the CLASS CONTRAST (panel-endorsed; powered by differences).** Δ = excess-co-miss(OMIT) − excess-co-miss(NUM), where excess-co-miss(c) = the difficulty-residualized cross-model co-failure on class c **above the same-tier two-Opus-draws baseline** (so uniform intra-vendor lineage coupling cancels). Δ > 0 (CI above 0, item-level-permutation FWER-corrected) ⇒ OMIT is *more jointly-blind* than NUM beyond difficulty and beyond shared lineage ⇒ a second tier buys *less* real coverage on omissions than on numbers. Δ CI covering 0 ⇒ no class-structured blindness. **Co-primary — joint-miss estimand:** P(all-panel-miss | class) with an exact beta-binomial CI, compared to a **difficulty-matched product-of-marginals independence baseline** via **item-level permutation** — well-defined at the p→0 catch rates OMIT is expected to show (where a binary correlation is undefined). Model-based read: a **mixed-effects logistic** (catch ~ difficulty[continuous] + class + model-pair + (1|item)); **n_eff** computed on the difficulty-residualized matrix, **descriptive-only, barred from every decision leg** (biased 1.98 vs true 3.0 at this N). CMH/Gwet AC1 within a frozen difficulty stratum: descriptive robustness only.

**Difficulty (identified out; SEALED before any run).** An ex-ante scalar per item computed by a **frozen, hashed, committable function of ITEM FEATURES ONLY** (`scripts/_doc277_itembank_core.py::difficulty` + the extension's identical function) — never any model's catch (circularity would deflate ρ→0). Instrument-adequacy gate: the covariate must clear a frozen McFadden pseudo-R² of marginal-miss variance per class, on a common IRT/Rasch scale, and survive a label-shuffle placebo (shuffled difficulty must NOT residualize the correlation away); a class failing → **R-INSTRUMENT-BOUND**, not headlined.

**Defect-class taxonomy (frozen, 4 classes):** {NUM, CODE, OMIT, MECH} — the 276 classes, assigned by executable predicate at seeding, no post-hoc rebucketing. "recompute-identity" is **not** a separate class; where H1 references it, it denotes the pre-registered NUM sub-flag `numeric-distance < 0.03` computed by the sealed difficulty function, reported as a descriptive covariate within NUM, never as a class.

**The item bank (certified).** Reused: the 17 potency-proven 276 seeds (potency already executed-proven; the one within-set-tell item R274_F5 rows-seed **excluded**). Fresh: a self-fabricated balanced extension targeting the thin classes (CODE/OMIT/MECH), each item potency-PROVEN by executed recomputation and **blind-solvable-certified** (the defect must be detectable from the artifacts furnished to the blind auditor — else excluded; this is the affordance floor's admission gate). Reused-vs-fresh is a pre-registered stratifier; a class verdict that flips between them is reported selection-bias-bound, not headlined. **Experimenter-expectancy is disclosed:** the extension is self-fabricated in-session (Opus AUP blocks fabricator subagents; Fable is rate-limited), mitigated by mechanical potency (executed, not judgment), executable class predicate, sealed feature-difficulty, and a balanced-across-classes plant that does not tune to H1.

**Two mandatory control arms (the panel's deep fixes):**
- **PROMPT-DIVERSITY arm.** Every model × every item is run under **two frozen framings**: (F1) "find any defect in this ruling"; (F2) absence-priming — "for each claimed computation/check, verify it was actually performed against the artifacts; flag any you cannot confirm." Joint-OMIT-blindness counts as a **model** blind spot only if it **survives both frames**. If F2 rescues OMIT catches ⇒ **R-PROMPT-BOUND** (the co-failure was a prompt-attention artifact, not a model blind spot).
- **AFFORDANCE-matched control.** A sighted arm where ≥1 model audits the OMIT/recompute items **with** the recomputation affordance the oracle used (tool access to run the check). If catch jumps from ~0 (blind) to high (sighted) ⇒ **R-AFFORDANCE-BOUND** (the co-failure was the harness denying the tool, not a shared blind spot).

**Multiplicity.** The family = {model-pairs} × {classes} × {estimators} × {frames}; FWER controlled by an **item-level max-statistic permutation** that preserves cross-pair dependence (not analytic Bonferroni on an assumed-independent family).

**Outcome decision tree (frozen; exhaustive; precedence top-down).** (0) **R-INSTRUMENT-BOUND** — difficulty instrument fails its adequacy gate, or the clean arm shows correlated false-positives, or potency/blind-solvability fails. (1) **R-PROMPT-BOUND** — the class-structured co-failure does not survive the absence-priming frame. (2) **R-AFFORDANCE-BOUND** — it does not survive the sighted control. (3) **R-DIVERSITY-ILLUSORY (H1-confirmed)** — Δ CI above 0 (permutation-FWER): OMIT is jointly-blinder than NUM beyond difficulty, lineage, prompt, and affordance; name the class, quantify the coverage a second tier fails to buy. (4) **R-DIVERSITY-REAL** — Δ CI covers 0 AND per-class joint-miss ≈ the independence baseline on powered classes: a second tier buys real coverage; the 276 rule vindicated for this panel, gain quantified. (5) **R-UNDERPOWERED** — too few powered cells to resolve Δ (the pre-registered fallback: per-class geometry demoted to exploratory; Δ reported with its achieved power).

**Frozen predictions.** **H1 (directional):** Δ > 0 — OMIT jointly-blinder than NUM (both tiers verify what is present, under-detect what is absent), and it survives F2 + the sighted control. **P-power:** with the achievable N, only Δ (the difference) is expected powered; per-class per-difficulty cells are pre-declared likely-UNRESOLVED (reported, never headlined). **P-clean:** clean-arm false-positive correlation ≈ 0 (else R-INSTRUMENT-BOUND).

**Scope caveats (frozen).** Intra-vendor cross-tier (all Anthropic) = near-worst case for diversity (Kim: within-vendor r > cross-vendor); results do NOT generalize to cross-vendor review — a within-vendor NUM null is uninformative about the cross-vendor case a practitioner deploys for independence. Pair/panel/seed-specific, in-sample. "Certified" = the oracle's potency + blind-solvability and the estimator's CI/power are proven, NOT that Δ is a universal constant. **Stage 1 tonight** = the Δ contrast headline; **Stage 2+ (gated)** = full per-class geometry at power-calculated N (~12–16/class) + cross-VENDOR replication.

The panel prompt (an audit task) ran cleanly on all tiers — unlike a *fabrication* prompt, which Opus's dual-use classifier blocks. Difficulty was sealed (`DIFFICULTY_SEALED.json` sha `322f48ad`) and the prereg committed (`9d9d0c6`) before any panel model ran; the independent authenticity peer (Sonnet) verified the seal timing from filesystem + git timestamps.

**§4.1 — The marginal picture replicates 276.** Per-tier catch on the specific seeded defects (F1): Opus NUM 8/8, CODE 2/2, MECH 3/3, **OMIT 0/3**; the other tiers similar on OMIT. Single-model omission-blindness (276's 1/3 recall) replicates and, corrected, is total on this bank — and it is **uniform across tiers**: a second and third Anthropic tier did not cover the seeded omissions.

**§4.2 — My first-pass headline, and how the hostile retest refuted it.** My initial analysis reported the pre-registered contrast Δ = excess-co-miss(OMIT) − excess-co-miss(NUM) = **+0.375, permutation p = 0.008**, plus a "prompt-rescue." **The mandated hostile retest refuted it — by finding a blind spot in my own scoring instrument.** The token-heuristic seed-matcher (`_doc277_seedmatch.py`) systematically **false-caught 2 of the 3 OMIT seeds**: the bridge-omission's entire numeric-token set was `{'2026'}` (a regex pulled it from a date), so any finding mentioning a 2026 date scored a spurious catch; the collider-omission "catches" fired on `'100'` (from `B=100`), `'+0.017'`, and `'liquidity'`. Hand-reading **every raw finding**, the retest established that **0/7 and 0/6 runs actually caught those two omissions** — the tiers found other real defects and never flagged the deleted spans. A second bug (a corrupted `brief` field on 6 runs) had also hidden the Haiku-F2 run that made the witness read as "both available tiers." Corrected (`analysis_corrected.json`): OMIT marginals **saturate at all-miss (1.0/1.0/1.0)**, so obs = exp = 1.0 under independence, **excess(OMIT) → 0.0, Δ → 0.0, honest item-permutation p → 0.33** (the 0.008 was a cell-shuffle null that *destroys the very tier-correlation it purports to test* — anti-conservative). Three independent checks (2 Opus retesters + the Sonnet peer) reproduced the correction.

**§4.3 — Why the class-geometry statistic is unidentifiable here (the design panel called it).** With reused catchable-by-construction seeds, the marginals saturate at *both* ends — NUM all-caught, OMIT all-missed — so the excess-over-independence contrast is 0 by construction and the correlation is degenerate (constant vectors). This is exactly the failure the design panel forecast in simulation: "the flagship OMIT class is the one H1 lives on and the one the design is least able to estimate — undefined correlations at low catch rates." The estimand cannot distinguish *correlated* blindness from *independently uniform* blindness at saturation.

**§4.4 — What survives (verified 3× independently, including a cross-tier Sonnet peer).** The single-item **existence witness**: the R274_F5 README template-omission — a deleted load-bearing check (the sole examination of the one per-fleet-varying file) with the conclusion "identical templates / no condition leak" left standing — is **jointly missed by all three tiers under both frames (7/7)**, while those same runs each produced 3–5 other real defects on the identical brief. The retest confirmed it is **blind-solvable** (the `diff`-the-READMEs tool was available and used nearby on the same sandbox; the tiers simply never generated the hypothesis) — a genuine *cognitive* omission blind spot, not a denied affordance. It is the tightest possible contrast: the same brief carries a NUM mutation every tier caught and an OMIT deletion every tier missed, in adjacent bullets.

## §6 — Implications and standing rules

1. **Automated audit-scoring is itself a blind-spot-prone instrument — hand-verify the catch layer.** A token/keyword seed-matcher false-caught omissions and manufactured a cross-model correlation that survived until a human-style hand-read. Any seeded-defect detection study (this lineage included, back to 276's own seed-match) must adversarially audit its *scoring* step, not just its subjects. This is the night's most transferable rule.
2. **Omission defects are jointly hard for a same-vendor multi-tier panel — a second model is not the fix.** A "deleted load-bearing check with the conclusion left standing" is invisible because the text *reads* supported; all three tiers missed the witness under both a naive and an absence-priming frame. Omission coverage will not come from adding a same-vendor tier; it likely needs an affordance change (recompute-every-claimed-check from scratch) — the Stage-2 hypothesis.
3. **Saturated marginals kill the correlation estimand — engineer difficulty to the middle.** Measuring cross-model error *correlation* requires items where each model's catch rate is near 0.5; catchable-by-construction reused seeds saturate both ends and make the contrast degenerate. Stage 2 must fabricate mid-difficulty OMIT items.
4. **The 276 rule ("use a different model") is not refuted but is *bounded by an existence proof*:** there exists an omission all three tiers miss, so a same-vendor second/third model gives false assurance on at least that omission type. Whether that generalizes is unmeasured (Stage 2 + cross-vendor).
5. **Design-panel simulation earns its cost:** the panel predicted the saturation degeneracy before the run; had I frozen the naive per-cell plan, the +0.375/p=.008 artifact would have been the headline. Pre-registration adversary → hostile retest adversary → cross-model peer is now a three-gate minimum, and each gate caught something the last did not.
